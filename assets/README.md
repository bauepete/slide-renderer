# Shared viewer assets

`exit.svg` is the editable door-and-exit pictogram for the class-materials viewer. Its original SVG geometry was authored for SYPPRE with Codex, following the door concept and gray treatment approved in the discussion. The conceptual reference was [Leave by Creative Stall, Noun Project #144676](https://thenounproject.com/icon/leave-144676/); no Noun Project download or third-party icon file is bundled. This SVG is maintained as project source, not as an asset licensed from Noun Project.

The SVG uses `currentColor`; `EpisodeOverviewLink.vue` supplies the course text color. Import it with `?raw` so the vector is embedded in the standalone presentation, with no network request. The generated discussion mockup is not a production asset.
